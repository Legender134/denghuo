# 灯火 · 破碎的像素地牢助手

Windows 本地悬浮助手与中文分析面板。读取 Shattered Pixel Dungeon 的存档快照，提供风险提醒、数值手册、背包说明、已探索地图，以及自动备份与明确确认后的回档。

首次启动直接打开游戏助手；已有启动偏好继续保留。原生「更多 → 设置 → 连接与启动」可查看和复制当前存档目录、重新读取连接设置，并选择启动时打开助手或完整网页面板。窗口可自由拖动、缩放，收起为可拖动灯柄后单击或键盘激活即可回到原页；「更多 → 恢复默认大小与位置」只重置几何，不清空工作。

随行窗口默认 380×460，已有自定义尺寸保留。「提示」优先显示与当前记录有关的机制和计算结果，例如首次与总治疗量、再次喝药的额外收益。逐条展开可看依据和计算条件；血量、等级、保存时间与存档操作收在底部的存档详情中。旧快照、手填和读取受阻会直接标出。

本地开发候选为 **0.6.0**；尚未发布到 Releases。下载入口下列的 0.4.0 是既有公开版本，本地候选需使用另行提供的试用程序。

## 下载与安装

**[下载最新版 Windows 安装包或免安装包](https://github.com/Legender134/denghuo/releases/latest)**

- **denghuo-setup-0.4.0.exe**：安装后从桌面或开始菜单打开「灯火」。
- **denghuo-portable-0.4.0.zip**：完整解压，保留 `_internal` 文件夹，双击「灯火.exe」。
- **denghuo-0.4.0.zip**：开发与许可用途的源码包，玩游戏不需要下载。

适用于 Windows 10/11 x64。安装版与免安装版不需要安装 Python。当前中文数值参考为 Shattered Pixel Dungeon 4.0.2；旧版存档的解析能力不代表当前游戏能继续所有旧档。

第一次打开即可使用：自动连接标准存档目录、跟随最新有效槽位，并默认开启自动备份和游戏内显示。不需要先配置；还没有存档时，直接开始一局，游戏保存后会自动连接。只有使用自定义存档目录时，才需要在「设置」中选择目录。需要回档时，完全退出游戏后选择备份并确认目标槽位。备份只包含游戏已经写入磁盘的进度，助手需要保持运行。

遇到问题可在 [Issues](https://github.com/Legender134/denghuo/issues) 报告：说明灯火版本、游戏版本、操作步骤及错误提示；不要上传个人存档、备份或设置，除非你主动决定分享它们。

## 启动

使用安装包安装后，点击桌面或开始菜单中的 **灯火**。免安装版本完整解压后，双击 **灯火.exe**。这两个版本均不需要安装 Python。现有目录也可双击 **启动灯火助手.cmd**，优先使用独立程序。

首次打开直接进入原生游戏助手，可用键盘访问提示、背包、炼金、本层与手册；装备比较可从背包进入；默认入口无需选择或配置，已有启动偏好继续保留。通过「更多 → 完整面板」可打开网页，设置中也可将它设为启动入口。默认浏览器无法打开时会显示管理窗口，并保留可手动访问的本次面板地址；不会更改入口偏好。原生窗口仍支持托盘、游玩显示与快捷键，读屏支持有限；完整面板提供带名称的表单，实际读屏体验仍需按所用辅助技术核对。管理窗口默认不置顶；首次跟随游戏时收为可点击的「灯」入口，展开后可直接操作。窗口大小、位置、所在页面和收起状态会保留，切到其他软件时跟随窗口隐藏。关闭管理窗口会收为可点击的「灯」入口，继续自动备份；关闭浏览器标签也不会停止后台辅助。管理窗口「退出」、托盘「退出灯火」或面板「结束本次辅助」才会停止监控。不会自动设置开机启动。

Windows 全局快捷键：**Ctrl+Alt+Q 收起或展开游戏助手、Ctrl+Alt+G 开关游玩显示、Ctrl+Alt+B 立即备份、Ctrl+Alt+L 显示管理窗口、Ctrl+Alt+H 数值手册、Ctrl+Alt+T 存档时光机**。可在原生窗口「更多 → 设置 → 全局快捷键」中修改或清空禁用，支持Ctrl/Alt/Shift加字母或F1–F12；重复组合会拒绝保存，被其他软件占用的键会提示。备份键只备份已保存进度，不强制游戏保存。

网页连接设置和备份位置中的「选择文件夹」使用 Windows 原生目录选择，只填写当前草稿。存档目录仍需保存设置，备份目录仍需预览并确认；取消或选择期间发生新编辑时，原输入和新草稿保持。源码版需先按构建说明编译原生控件；当前系统或控件不可用时可继续手填路径。

点击「手册」先显示已知且可用的装备快照资料与常用药剂、卷轴；输入名称后按 Enter 直接打开首项，按向下键进入结果列表，Ctrl+F 返回搜索。填写数值后也可按 Enter 计算。更多结果可继续加载，空搜索也可浏览完整资料。新打开的资料会带入公开局势中适用的角色数值（如生命、上限和角色等级）；从装备快照打开时还带入已知装备等级和阶数。未知等级按 +0 示例，其他参数标明示例或手填。重新打开会更新装备入口，已打开资料的手填内容保留；快照变化或过期会提示核对。

侧边栏用于页面导航，本层资料通过正文上方的「本层参考」按需展开。窄窗先呈现当前任务，点击同一页也能返回正文。隐藏内容揭示后直接列出秘密门与陷阱坐标，地上物品、容器和已保存生物分别折叠，避免长列表挤走怪物资料。本层参考会随当前保存楼层显示可能出现的怪物；每种默认折叠，只显示名称、生命、普攻和减伤，展开可看具体数值、掉落物与条件概率。常见怪物直接列出，稀有变种、房间与任务条件、饰品生成条件、首领支援分别收在折叠分组中；刷新同一楼层或角色升级保留展开状态与可辨认的阅读焦点，并更新数值。乌木宝箱怪另注明宝箱怪之牙的生成分支概率；召唤怨灵使用固定等效第4层属性，召唤骷髅显示初始生命20/25。名单区分普通轮换、互斥任务和条件召唤，不代表本局一定出现；4.0.2尚未实装的菌类任务不列入正常名单。隐藏门、未显陷阱、容器和生物随身物品需点击「揭示本层隐藏内容」后查看；可继续进入完整地图。保存快照或连接变化后隐藏内容自动收起。原生管理窗口提供同样的折叠树与完整资料入口，选中已主动揭示的楼层物品也可直接查看数值，使用该物品的已保存参数作为独立参考。

本层名单会读取已保存的绝命头目挑战条件，切换已核对的首领初始生命、支援名单、拳头配对和能量塔数量。挑战未知时明确按普通条件参考；完整资料可手动调整挑战开关。仅明确标出的机制分支已切换，其他挑战变化仍需结合资料核对。宝库扫描与激光机关按房间条件单列折叠，不作为可击杀的普通敌人。

搜索怪物名称可查看正常状态的生命、伤害、命中、闪避、减伤、经验、移动速度与普通攻击耗时，以及具体掉落物、数量、概率和触发条件。固有抗性、免疫和有条件无敌分别列出；不是所有伤害都受同一个系数影响。覆盖 4.0.2 官方图鉴全部 85 种敌人，并区分召唤体、宝库变体及不可破坏的机关。可调整角色等级、生成层数、本局累计生成次数（含成功偷取）、当前目标是否已被成功偷取普通战利品、蝇群分裂代数、适用的财富有效加成、击杀时生效的赏金猎人点数与准备攻击等级、遗忘碎片生效等级与合格未鉴定项数，以及异晶生效等级（饰品−1为无效果）；递减掉率与固定首领奖励分别计算。财富输入是生效加成，单枚正常+0戒指填1；普通掉率最高100%，财富额外战利品另计。当前目标已被成功偷取时，普通掉落为0，独立固定奖励另计；失败偷取不关闭普通掉落。赏金猎人须同时填写击杀时有效的标记点数和准备攻击等级，先与财富加法合并，再计适用的遗忘碎片；没有生效标记时点数填0。遗忘碎片需手填确认生效等级和合格项数，普通掉率倍率与财富按加法叠加；五个装备槽及两个近期使用标记最多7项，实际计入不超过碎片生效等级＋1项，不会从未知背包推定。固定奖励与绕过普通掉率方法的宝库变体另计。异晶只对已核对的直接指定药剂／卷轴掉落进行互斥转换，不套用到绕过该分支的随机池或固定任务奖励。敌对新生火焰元素死亡的1份余烬独立列出。展开资料还列出六类古神之拳的远程、环境与承伤机制；污土之拳可填写周围草丛格数，腐烂之拳可填写来源抗性结算后的伤害查看流血参数。宝库怪物按实际继承列出能力和自身传送限制。无局势时默认角色等级 1、累计生成 0 次、未成功偷取、赏金猎人 0 点、准备攻击等级 0、财富加成 0、遗忘碎片−1、合格未鉴定项0、异晶−1，这些是参考条件。神器按初始可用池列出，实际已生成神器会改变分布；宝箱怪、石像在生成时确定的战利品不能由普通掉率表推断。

已核对的特殊机制另列条件与单位，例如史莱姆的伤害压缩、幻影食人鱼的距离减伤、跳跃恶魔与白化鼠的流血首跳、酸液蝎的淤泥、蝙蝠吸血、武僧专注、食尸鬼复活以及腐莓核心的燃烧掉落例外。另列元素点燃、冻结与传电条件，死灵召唤、守卫铁链、魔像拉回、盗贼逃跑受击金币、蝇群分裂及恶魔血巢的压缩与冷却。豺狼流寇另列两格长矛的路径阻挡和条件性被动行为；黄金与乌木宝箱怪区分生成抽取数量、去诅咒范围和+0非神器的升级概率。水晶宝箱怪另列极速、偷取、目标移位以及触发逃脱后的携带物损失条件。矿洞另列水晶守卫倒地恢复、水晶尖塔波次与警告、豺狼投石和落石；宝库首领按火焰、冰霜和电光形态列出攻击、生命阶段与冷却，蜘蛛吐网区分体积、扎根和冷却。气体体积、状态强度和冷却计数分别标明，不能直接当作伤害或角色行动次数；其他未列分支仍需结合游戏状态核对。

当前酸蚀资料会带入游戏公开的整数强度和最多两位小数的时长，显示剩余基础总量范围与逐次伤害；只有明确选择手填精确假设时才计算单一序列。缺失强度或时长保持空白待确认。延缓伤害单独计算当前剩余池、下一次基础伤害和扣池后剩余，不套用新命中的刻印分摊。二者均不预测行动时序或防护后的实际生命损失；带入最新条件可撤回，保存方案保留参数、来源与精度。

物品与怪物名称带下划线和官方像素图，悬停或键盘聚焦可看摘要，点击打开完整图鉴（玩法说明、具体数值、掉落与出现条件）。随机药剂、卷轴和戒指优先使用本局公开外观；资料库的效果图标与可变化的代表外观另作标注。图像来自固定版本官方素材，可离线使用。

需要提前查看未知物品时，可在物品详情主动揭示这一件；关闭详情或快照改变后失效，不改变游戏鉴定状态，也不开启全局揭示。需要整体查看时，可在连接设置中主动开启揭示。背包真实身份和等级可继续打开数值与装备对比；游戏的鉴定状态保留，主动揭示会单独标注，未知消耗品不会自动成为已鉴定资源建议。关闭后，背包和当前资料入口恢复隐藏。

「楼层探查」单独选择本局已生成楼层，默认不展开隐藏内容。勾选并点击揭示后可看完整保存地图、隐藏门与陷阱坐标、地面和各类容器内容，以及宝箱怪、石像、盗贼随身保存的物品；可点击物品查数值。仅只读解析官方4.0.1/4.0.2已保存内容，不代表实时视野或可立即取得的奖励。地图中的秘密门不用于猜测房间名称；随机死亡掉落查怪物手册。切换存档或保存快照变化后会收起旧探查，重新选择并揭示；尚未生成的楼层不会冒充已保存内容。

同页的「接下来能找到哪些装备」使用 [Shattered Pixel Dungeon Seed Seeker](https://github.com/akhial/shpd-seed-seeker/tree/b3596f5c0d26852acc20bb6de4f2169ebcbdd24a) 的固定4.0.2引擎离线计算。手填九字母种子/UTC每日日期，或主动读取本局种子；确认参考条件后生成第1–24层的装备、升级、诅咒、附魔/刻印、来源、房间类型与互斥奖励，并可筛选和查数值。无须联网或安装Rust，默认不计算，可随时取消。

这是一种**独立的新局参考情景**：战士、无挑战、不装备饰品、无遗骸奖励，按主楼层顺序生成；教程已完成，日志采用引擎基准（除地狱国王的损耗页外均已读），没有游玩造成的生成状态变化。读取当前存档种子也不会恢复其生成器牌堆、掉落计数或其他游玩状态。因此它不能保证当前冒险的实际未来，4.0.1存档的种子也只用于4.0.2情景。只覆盖引擎支持的静态装备、初始饰品候选和房间类型，不涵盖全部消耗品、随机死亡掉落或精确坐标。神器显示等级不直接套用内部等级公式；已生成楼层的实际物品与位置请使用上方存档探查。


多个助手会话共用配置时，旧会话不会覆盖另一个会话新保存的连接设置。发生冲突后，草稿仍保留；点击「重新载入已保存设置」会实际重新读取磁盘配置，再核对需要的修改。

源码版需要 Python 3.10+ 与 Tk；原生交互窗口需按 [构建说明](BUILD.md) 编译辅助程序，Windows 独立版会预置该程序；不安装桌面依赖时，关闭悬浮窗会最小化到任务栏，仍继续监控。明确打开完整面板可运行 `python -m companion --web`；仅面板且不启动原生窗口可运行 `python -m companion --no-overlay`；只开原生窗口可运行 `python -m companion --no-browser`。希望启动时只保留托盘和游玩显示，可加 `--no-browser --start-hidden`。

重复双击按已保存的入口偏好复用正在运行的面板或管理窗口；`--web` 明确打开完整面板。启动失败时会显示原因，独立版的详细信息写入 `%LOCALAPPDATA%\Denghuo\startup-error.log`；源码版写入 `.local/startup-error.log`。若 Tk 悬浮窗不可用，可按提示仅运行网页面板。

## 游戏中怎么用

1. 开始或继续游戏，保存后等待约 2 秒。
2. 切到游戏前台，点击「灯」入口展开原生工作区。可拖动标题栏、拉动边缘调整大小；点击「收起」或按 Esc 会留下小入口，再点即可回到同一页面和原始输入。「更多 → 恢复默认大小与位置」只恢复窗口布局，不清空草稿或个人设置。
3. 在同一窗口查看局势与实际背包、查数值、比较装备和升级预算、规划炼金，或从「更多」进入角色条件、保存地图和存档历史。未知身份仍保持未知，隐藏内容需要主动揭示。Ctrl+Alt+Q 开关工作区，Ctrl+Alt+H 进入数值，Ctrl+Alt+T 进入历史；回档先核对预览并完全关闭游戏。
4. 数据过旧时，回到游戏主菜单让游戏保存后继续；也可在「角色推演」中输入画面中的状态。

助手读取的是磁盘存档，不读取进程内存，不承诺逐回合实时同步。旧快照显示保存时间和明显提示。游戏仍在当前楼层战斗时，存档可能尚未更新。

游玩状态条默认直接显示快照生命和备份状态，出现实际风险时再显示首条风险，无需先按快捷键；详细装备数值可展开工作区查看。状态条和只读卡不会抢游戏焦点，地图点击能穿过；状态条在位置拖动模式接收鼠标，灯入口始终可点击展开。新存档首次出现新风险时短暂提醒，默认5秒；启动时、旧存档、读取失败及手填局势不自动弹出，持续的同一危险不反复提醒。正常备份不弹通知。可以调字号和背景透明度，文字保持不透明。

游玩状态条与只读卡不抢焦点，点击可穿过；「灯」入口与展开的工作区接收鼠标，编辑表单时会取得键盘焦点，独占全屏游戏可能暂时最小化。按 Esc 收起工作区会尝试返回已核对的游戏窗口。不承诺所有显卡、显示设置或改版游戏都能显示覆盖层。未实现画面识别或实时倒计时。百科参数明确标为参考示例，修改后清除旧计算，固定卡也注明参数与条件；不把示例当成当前角色。

手动局势不会自动跟随游戏，超过一分钟会提示重新填写。手动输入只保存在本次运行中；重新启动后自动回到存档读取，保留原先选择的目录与槽位。需要推演时再打开「更多功能」填写。

保存过程中检测到文件变化会自动重试。地图早于角色快照或时间明显不一致时，暂不展示地图；复制来的存档若改变了文件时间，也可能触发此提示。

损坏的压缩数据、无效数值或不完整的角色字段会显示读档错误，不会修改或“修复”原存档。助手仍可打开，新的有效保存到达后自动恢复。

标准路径：`%APPDATA%\.shatteredpixel\Shattered Pixel Dungeon`。设置里可选择其他根目录和 1–6 号槽位。自动模式跟随最近更新的有效存档。

自动模式找不到可读存档时，会显示最近更新槽位的具体错误；固定选择的槽位尚未保存时，会提示先保存或重新选择。新的有效存档到达后会自动恢复，无需重启。

已保存的自定义目录暂时离线或被移动时，会提示恢复目录或重新选择；不会自动改读默认目录。原目录恢复后可继续读取。

设置文件损坏或字段无效时，助手暂停自动读档。到「连接设置」确认目录、槽位和其他选项，再保存即可恢复；原文件会先保留为同目录下的 `settings.recovery-时间编号.json`（使用自定义配置时沿用其文件名）。备份失败时不会覆盖原配置。

## 可复用的资料与决策

数值手册支持血瓶、力量药水、升级卷等常用别称和回血等需求查询；没有匹配时给出明确建议，不会由资料查询鉴定游戏中的未知物品。手册首页和桌面速查共享已知可用的当前资料、收藏、最近查看和常用参考。网页搜索支持 Enter 打开首项、向下键进入结果、Ctrl+F 返回查询；F1 随时打开帮助。

公开存档中已确认学会的牧师法术会出现在当前资料，并按该技能自己的天赋投入带入数值；未学、不适用或无法确认的技能会明确说明，手册示例单独保留。网页及原生手册可明确带入最新角色条件并撤回，已保存方案和手填内容不会随轮询更新。学会技能的记录不代表当前充能、冷却或施放目标已满足。

数值计算、装备比较、共享角色条件、手动局势和炼金规划可分别命名保存为方案，填写用途备注，明确更新、另存、移除，或导出后合并导入。方案保留固定参数、字段来源、原槽位/快照时间和资料版本；打开不会自动替换为另一个角色的数值。手动方案只填入待核对表单，明确提交后才应用，启动仍默认自动读档。历史方案另存副本会保留当前未保存输入；保存等待期间新增的编辑也继续保留为草稿。同一页面会话里尚未计算的原始输入也会按方案分别保留，空值和半输入仍明确提示未计算。更新和删除会核对打开时的记录版本，另一面板已修改时拒绝陈旧确认并保留草稿，可另存或明确重新读取。工作区可按名称或备注搜索、类型筛选和更新日期或名称排序。读取装备或炼金方案期间产生的新编辑会保留，需要时重新打开方案。重复导入相同内容会跳过已有副本；已经编辑的导入副本保持，原内容缺少时只新增一份，JSON 与迁移 ZIP 使用相同的内容核对原则。

「共享角色条件」保留基础力量、已知戒指、力大无穷天赋和临时力量状态，并列出总力量的来源。可带入含力量参数的数值试算、装备比较和手动局势草稿；带入可撤回，其他原始输入保持。比较戒指时明确替换哪个槽位，分别计算A、B和升级后的总力量；不会重复佩戴原戒指。空白或未确认条件保持待确认，固定参考不会随新快照覆盖。

装备比较的固定方案和复制文本保留当时公开的装备名称、效果身份与用户备注，便于区分同种装备；这些辨认信息不额外计入数值。旧数值方案若已无法计算，仍可查看完整原记录、导出，或明确修改参数后另存，原方案保持保留。

普通近战比较可按需启用综合条件，合并共享角色里已确认的武力、狂怒和精准戒指效果；原基础指标仍单独列出。可为手填目标条件命名，分别填写基础命中、目标闪避和减伤上下限，未确认的字段留空。条件随方案保存、导出和重开，不推算未探索敌人或下一击。不可用的旧装备方案会保留原字段、来源与备注，可选择当前支持的替换装备，比较后另存修正版。

资料库损坏时可先预览健康、损坏和重复冲突记录，单独导出健康记录，或明确确认完整保留原文件后恢复健康子集；重复身份不会自动选取某一条。无法判断记录结构时才提供保留原件后建立空库。当前不可用的收藏仍可逐项取消，释放收藏名额。

正常快照刷新会保留同一局中的风险说明展开状态及仍可唯一辨认的列表焦点；地图区分可通行水面与不可通行水面装饰。数值方案首次保存、另存和明确更新后仍保留后续原始输入；保存期间产生的新计算会标明尚未保存，不会冒充刚保存的结果。

装备升级和预算按实际显示等级计算：法杖带入公开树脂，每卷升级先消耗一层树脂，显示等级可能保持不变；诅咒注魔由用户明确填写假设，硬化按公开状态核对。保留或移除诅咒效果、硬化失去及法杖解咒分别列出可达分支，不把随机结果当作保证。注魔未确认时仍可查看当前数值，升级和门槛保持待确认；这些条件可保存并重开。游戏内已有的物品名称和备注在背包、详情及桌面速查中另列为用户记录，不改变官方规则说明。

风险提示可直接查看相应状态和装备资料；已确认可用的资源可进入对应计算。治疗区分首次恢复和最终量；行动限制、零生命、药水恐惧、遗落物品、已存在治疗和版本差异不会被当作已确认治疗量。水袋可按所填生命、露珠量、护盾露珠天赋、现有屏障和凝血试管计算耗用、即时或逐次恢复与实际新增屏障；未确认条件仍是示例。背包水袋入口会带入公开记录中的露珠量（含空袋）；已知屏障和水袋露珠量也可从公开保存记录带入，未确认的护盾天赋仍需核对。饥饿风险可连接已知可用食物，显示基础饱食、进食回合及挑战、节庆等限制；进食不等于即时回血。装备比较给出力量门槛、升级变化、单位与条件；按需启用预算，可选达到门槛的最少投入，或查看从零到预算上限的完整投入备选，核对最终等级、力量缺口、消耗、余量、单位及生效条件，每件备选独立使用同一预算，不实际消耗资源。已鉴定负等级普通装备可在资料与比较中按原等级试算。

「帮助与关于」提供版本、离线常见问题、当前状态的恢复入口及本次数据/日志位置。排查摘要可先预览再复制或导出，严格不含个人路径、存档、背包、方案参数、日志原文或服务口令，不会自动发送。数值详情按需展开官方依据，链接固定到随包资料的游戏提交，并标明计算的限制。

网页「游玩显示与快捷键」包含完整配置，和桌面共享；保存后单独显示实际应用及注册状态。两处同时修改时要求重新核对，不静默覆盖草稿。原生工作区使用暖纸色、深色顶栏与灯火金的 WPF 界面，顶部切换局势、背包、炼金、本层与手册；背包直接进入装备比较，局势可调整角色条件，本层可查已探索地图；存档历史固定在底部，设置、方案与草稿位于分组菜单。标题栏可直接恢复默认大小与位置，背包与资料使用随程序提供的游戏原始图像，未鉴定物品保留公开外观。手册按搜索、阅读、条件编辑分开呈现；治疗详情先给实际恢复与首次恢复，完整明细和依据可展开。修改条件后旧摘要收起，计算与保存状态分明。连接与启动选择后立即应用，游戏提示与快捷键需点击保存，页面分别说明。表单与结果各自使用完整阅读区，提供控件名称、当前值和键盘入口；完整网页面板也提供有名称的表单。辅助技术仍需按实际环境核对，不宣称未经实际验证的读屏体验已达标。

「炼金规划」覆盖4.0.2的39个官方配方族，包括转换、烹饪、强化炸弹、树脂提炼、整堆投武熔炼和饰物选择与升级。按希望制作的产出件数添加目标，所有目标按顺序共享同一份库存、保留量和能量；唯一确定的前置路径可连续展开，多种材料选择需明确指定。每件物品或原始堆单独登记，等级、生熟、耐久和已显示四选项保留各自条件，未知与随机结果不会变成后续步骤的确定材料。可预览当前库存的配方候选，再加入目标共同计算。带入已知资源可撤回，不猜测未鉴定物品或精确耐久。目标增删、顺序、材料选择及原始输入可统一撤销或重做，含无效输入；新编辑会清除重做分支。结果和用途备注可命名保存；旧单配方方案继续按原来的批次语义打开，明确转换后才成为产出目标副本。

「搬机迁移」可选择存档历史、方案、收藏、已保存未完成草稿和便携游玩偏好，先预览再导出或导入。历史只加入助手备份库，恢复游戏仍需单独确认；原始草稿只保存副本，需另行明确载入，不计算或应用。旧机器的存档目录、窗口位置和服务口令不会携入；草稿文字里的机器路径与标记秘密会脱敏；公开 HTTP/HTTPS 链接保留。带引号的值按完整内容省略，未加引号的 Cookie 或未闭合引号按整行保守省略；含空格路径省略到引号、分号或换行等边界。导出预览显示实际副本文字，本机原始记录保留；未标记的任意秘密仍需自行核对。导入后按类别显示真实成功、冲突副本或失败，以及偏好是否实际应用；已提交结果持续保留，重新选文件不会丢失旧回执，失败重试只针对原操作的失败项目。连接新机器的自定义存档目录仍通过「连接设置」。恢复迁移选择草稿时需要重新选择原ZIP并重新预览。

全局成就与排行榜可另外选择 `badges.dat`、`rankings.dat`，默认和「全选常规项目」都不选。来源版本未知时可导出留存，本版仅允许明确核对声明为4.0.2的文件导入；文件本身不能证明游戏版本。导入前逐文件选择保留或替换，完全退出游戏并单独确认。替换整份文件，不合并统计；原件和输入先留在备份目录，游戏目录内的本事务暂存也保留。中断后可从迁移页预览恢复导入前原件；外部改过的新字节不会被覆盖。普通槽位回档不恢复这些全局文件。

自动备份默认也独立保留成就与排行榜的原始历史，即使尚无有效局内槽位也会捕获文件变化；内容不变不重复保存。每个存档目录的活动历史最多512份、64 MiB，容量满后保留已有历史并提示新增受阻。可先预览，再明确确认将整份活动历史原样保留为本地归档，随后重新捕获当前文件、继续保护新变化；这只恢复活动额度，磁盘占用不会减少。保留归档仍可浏览、导出和逐文件恢复；中断后先核对关联再继续或取消。损坏清单单独显示并可导出原件，其他健康记录仍可用；同一记录中的独立健康文件也可单独选择。在「存档时光机 → 成就与排行榜历史」中可搜索所选活动库或归档的全部历史（日期、内容、编号），按文件及可恢复、仅完整原始副本、损坏状态筛选；轮询保留查询与同一记录操作的键盘焦点。还可查看、导出原件，或核对版本后逐文件恢复、导出可供搬机迁移页导入的包。异常结构只保留原始副本，不会据此宣称进度已保护。备份位置切换意外中断时，备份页会保留恢复关联，核对原件后可明确继续或取消切换。

方案与收藏库正常保存后，助手在本机保留最近三代经过核验的健康副本；已有健康资料库首次读取时也会建立保护。主库损坏时，从资料库恢复预览选择健康副本，核对方案、收藏和最近条目后明确恢复，损坏原件完整保留。主文件缺失且已有副本时暂停写入，浏览资料不会轮换掉原有健康副本；需选择可验证的来源、重新预览后明确恢复，也可只导出。恢复前主文件重新出现或来源变化时停止，不覆盖新原件。全部副本都不可验证时可明确建立空库，副本原字节保留。全新用户没有这些副本时仍可直接使用。健康副本写入失败会单独提示，已保存的主库保持；健康副本不替代搬机导出或外部备份。

通过面板、托盘、快捷键或原生窗口请求退出时，未完成草稿可选择保存副本、取消或明确放弃。副本保留半输入的原始文字和备注，下一次从「未完成草稿」明确载入，不会自动计算、应用或覆盖原方案。连接和游玩设置按原来实际修改的字段恢复；同字段冲突先核对原值、当前值和草稿，未修改字段保留最新配置。离线原生副本可分别载入数值或游玩表单。处理完成后可明确归档，默认列表只显示未完成副本；勾选「显示已归档」可恢复，原始文件和身份保留，搬机携带归档状态。结束前会分别尝试保存各槽位和成就、排行已写入磁盘的最后稳定进度；没有槽位时也会检查全局文件。网页结束前会独立上报本次原始输入；上报失败或期间继续编辑时保持当前窗口并说明原因，重新请求结束前不会继续退出。网页和原生面板保留本次结束的最后备份结果，列出已确认的槽位与全局文件，区分全部完成、部分完成、无存档、主动暂停与失败；失败原因保留并在下次启动提示，不保证捕获未落盘的游戏进度。

退出时优先校验已保存的当前全局副本，避免满容量历史拖慢最后备份，并为普通存档保留检查时间。退出回执确认的是本次进度对应的副本；完整历史的损坏情况仍在「存档时光机」中显示。

编辑时会自动保留最近已上报的原始输入。异常中断后，网页和原生窗口会提示可找回副本，需在「未完成草稿」明确载入或归档；不会自动应用。写入失败或空间不足会明确提示并保留现有原件，当前窗口仍可明确保存草稿副本。尚未上报的最后编辑不保证找回。

自动保留尚未完成时会明确显示等待状态。退出确认中的草稿保存较慢时仍可取消并继续编辑；已经开始写入的副本可能稍后完成并保留，不会覆盖新输入或确认后来发起的退出。

## 功能

- 低血量、饥饿、燃烧、腐蚀淤泥、酸蚀、流血、移动受限和挑战模式提醒。
- 复活后遗落行囊时，仅将确认保留的物品计入可用资源，避免把丢失的药剂当作救命手段。
- 嵌套背包与装备整理；未知效果、等级和诅咒保留未知。可在设置中主动开启剧透模式。
- 显示最近存档中已探索的地图。隐藏未探索区域与未发现的暗门、陷阱，不展示存档内的敌人位置。
- 中文数值手册：查物品、敌人、职业、专精、天赋、技能、状态与机关，按官方游戏4.0.2整理（当前条目数量见手册首页）。按名称或关键词搜索，点击后直接看数字。
- 装备等级表：伤害上下限、护甲减伤、力量需求、命中倍率、攻击耗时与距离。已鉴定装备从背包点开时自动带入已知等级；未知等级按+0示例，支持手动调整到+100。
- 背包中的「装备与升级对比」可展开比较两件同类别的普通近战武器、可升级投掷武器、护甲、法杖或戒指的现在/+1数值，计入所填力量、精通药剂和强化。A 尚未自行修改时优先带入当前已知且可用的主武器或护甲；手选条目与手填条件保留。力量不足的攻速、命中、移动及减伤惩罚直接给出；武器额外防御单列。职业护甲沿用实际原护甲阶数，快照变化会提示重新比较。
- 15种普通可升级投掷武器可从已知可用背包详情直接进入比较，保留所点装备的等级、精通和强化；支持最小力量门槛或完整预算投入，并命名保存固定条件。相邻/非相邻命中、空格投掷、手里剑快速投掷及回旋/群体效果分别标条件，不推断当前精确耐久或安全投掷次数。飞镖和灵能弓不纳入这一普通投掷比较。
- 升级卷轴显示当前等级的普通附魔/刻印损失、硬化保护损失和诅咒移除概率；近战/护甲、投掷、法杖/戒指及硬化分支分别呈现。连击页显示命中、击杀后的保持时间以及相关天赋变化。
- 效果计算：输入生命、层数、力量、目标生命或天赋点数，得到治疗、护盾、伤害、触发概率、击退距离和持续回合。数字旁边注明生效条件；不需要自己读公式。
- 治疗药剂区分治疗额度、真正恢复量及每次恢复明细。例如生命10/100、没有凝血试管时：额度94HP，实际恢复90HP，首次恢复24HP。
- 已有治疗状态显示最近保存的剩余治疗量，手册带入实际恢复速度与限速；未知条件留空。已知治疗药剂可比较等待与再次喝药的首次、未来恢复及额外收益，分别合并各项治疗条件，不重复增加原治疗池的饰物加成；结果不预测敌方伤害或安全等待时间。
- 戒指正常/诅咒对照，饰物升级对照，神器容量与升级效果。职业技能、刺客蓄力、武僧武功、首领阶段和绝命头目挑战分别列数值表。
- 合成材料、能量成本及产量直接列出；可查看24个简单炼金配方与10种强化炸弹配方。出售与炼金回收显示单件基础收益，商店买价另计。
- 神器显示容量、升级需求、充能速度及使用成本；神偷袖章可填写物品基础售价和当前充能，直接计算成功概率。持续治疗可填写剩余治疗池与来源速度，不会重复增加饰物加成。
- 存档时光机：每 10 秒检查各个有效槽位，保留一小时、半小时、10/5/2/1 分钟及 50/40/30/20/10 秒的时间节点；首次开启需要等待积累。相同存档内容去重，不重复占用文件空间。助手关闭期间不备份。
- 完整备份历史不随一小时窗口消失，可按名称、日期、职业、楼层搜索和筛选固定记录。卡片突出实际游戏保存距今的时间，相同进度的节点合并。重要备份可以命名、固定、导出、导入和独立校验；未保存的名称和固定标记在关闭弹窗后保留，也包含在退出草稿副本中；保存期间的新输入仍待保存，搬机或切换目录后的编辑需重新核对关联。导出的 ZIP 携带名称、固定状态和原观察时间，导入后另列登记时间，重复导入保留本机设置；移出后可在保留库校验并重新加入，原名称和记录时间保留。总占用分别列活动库、移出副本、损坏隔离及回档前副本。
- 恢复与撤回前都并排核对当前与目标进度；恢复后可在软件内「撤回上次回档」。两个操作都要求完全退出游戏、勾选具体槽位确认并通过文件校验。预览后当前进度或存档连接发生变化，会要求重新预览。原生窗口保留操作回执；失败会保留所选记录，修正原因后重新预览并确认。完整面板在确认窗中显示失败原因。首页、悬浮窗和托盘同步提示当前槽位的自动备份暂停或受阻。
- 时间记录损坏时，可明确确认后「校验并恢复时间记录」：先保留原记录，再校验已有备份并恢复历史。名称、固定标记和可撤回记录保留；无法确认的旧时间节点重新积累，未有观察时间的备份明确标记。其他管理记录也损坏时会停止并保留原件。
- 手动局势分析、装备力量需求计算、存档变化记录。
- 手动推演支持主地牢/任务支线、15 种状态与 9 项挑战；可带入当前快照，或直接回到存档读取。未填写的资源不会伪装成已确认的零数量；未确认的饱食状态保留未知，手动带入也不会改成“尚未饥饿”。
- 装备力量核对、已鉴定的力量药剂/升级卷轴规划、已知诅咒对应的祛邪资源提示。未知物品不会被当作已确认资源推荐。
- 神器等级按游戏显示值换算，职业护甲按原护甲阶数核对需求；力量速算支持普通近战武器、护甲与巨斧。
- 可选的工具自动停止时间，按北京时间解释，默认关闭。开发工作截止时间不会停止工具。

数值页先显示计算结果，玩法说明可按需要展开。每个参数标明快照、物品已知值、示例或手填来源；快照过期及修改后未计算会明确提示。点击「带入最新角色状态」更新角色参数，保留其他手填条件。力量参数使用已确认角色条件算出的总力量，并可查看基础力量、戒指、天赋及临时状态的分项来源；条件不完整时提示待确认，也可明确手填游戏面板数值。小数最多显示六位有效数字。回合是游戏时间，不是现实秒数。

各表注明基础条件。其他装备、天赋、精英、抗性和临时状态可能改变结果，特殊组合不能直接套用单项基础表。旧版存档可读取，参考数值以4.0.2为准；6个已移除的旧版条目明确标记。

麻痹、冰冻、魔法睡眠和时间静止期间会优先显示行动限制与风险。漂浮、缠绕会影响用水处理燃烧/淤泥的建议；零生命的狂战士会提示核对狂暴护盾，而不会直接判定死亡。

变化记录只比较同一局的快照；切换槽位、种子变化或重开同一种子时重新记录。读取暂时失败不会把恢复后的生命值当成另一局。

## 本地数据

日常分析与备份只读取用户存档。只有在「存档时光机」选择备份、勾选目标槽位确认，并通过游戏关闭检查后，才会恢复该槽位。恢复前完整槽位目录另行保留；恢复失败会尝试还原原目录。其他槽位和全局成就/设置不恢复。

自动备份默认开启，也可在页面暂停；立即备份不受暂停影响。独立版的备份、索引和开关保存在 `%LOCALAPPDATA%\Denghuo\backups\`，源码版保存在 `.local/backups/`，不同存档根目录分别管理。备份记录时间与游戏保存时间分别显示：游戏尚未保存时，多个时间节点可能是同一游戏状态。不会强制游戏保存或读取内存。

「游玩显示与快捷键」中的备份存放位置可选填另一块本地磁盘上已存在的文件夹，留空使用默认位置。先预览并校验各库、保留区和隔离区，明确确认后复制并切换；原目录和目标原记录都保留。已有历史按编号合并，目标名称和固定状态保留，字节冲突停止。每次复制限 2 GiB、20000 项，活动 ZIP 仍限 512 MiB。选定磁盘离线或身份不符时暂停备份并提示，不自动改存别处；如需先继续，可明确选择保留离线旧历史，在新位置备份，本次不会读取或复制旧历史，重连后再预览合并。位置草稿可找回，但载入不会应用或复制。备份目录属于本机配置，不随便携偏好迁移。位置预览若发现中断自动整理，会先列出确切原件和退回位置；明确确认后仅恢复原件，保持当前位置和所选目标草稿，再重新预览复制。

「备份空间」可选择一次预览并明确启用当前库的自动保留策略，默认关闭。启用后，每槽至少保留最近20份（时间相同的记录一起保留），固定、最新、撤回和中断关联记录保持；只有活动 ZIP 或历史项额度不足时，才将本库较旧记录移入可重新加入的保留目录，向384 MiB活动目标整理。其他库不会自动处理；可整理记录不足或物理空间不足时暂停新增并说明原因。移出不释放物理磁盘空间，原ZIP完整保留。可随时关闭策略；切换备份位置后，复制来的授权关闭，需在新位置重新预览启用，目标已有自己的授权则保持。预览确认不随未完成草稿恢复，需重新核对当前库。中断整理会在后续写入前先恢复原 ZIP 和索引，之后的重命名、校验和导入可正常继续。策略文件损坏时自动整理保持关闭，可在同一区域预览并完整保留坏原件，重建为关闭策略；重新启用仍需再次预览授权。

全部助手备份库的活动 ZIP 共用 512 MiB 额度，达到上限停止新增并提示，不自动删除原备份。存档时光机中的「全部备份库」可查看以前连接目录留下的库，按库编号、角色及槽位核对后导出、预览手动整理或重新加入保留副本。选择旧库不会切换当前游戏连接；固定、每槽最新及撤回关联记录始终保留。移入保留目录只调整活动额度，不释放磁盘空间；旧版未登记来源目录时会明确说明。无链接的标准槽位目录受支持；游戏仍在运行、潜在游戏进程无法核对、备份校验失败或楼层不完整时拒绝回档。已确认与游戏无关的 Java 程序不会阻止回档。恢复页面显示备份的存档版本；4.0.2 游戏不支持继续版本码低于 850 的旧档，助手能解析旧档不代表当前游戏能加载它。旧备份记录若没有版本信息，请核对所用游戏版本。Steam 云同步可能随后覆盖本地回档，应核对重新进入游戏后的状态。

「占用与手动整理」分别列出活动历史、移出副本、损坏隔离和回档/撤回前完整目录的数量、占用与保留原因，可主动打开对应目录或导出具体保留副本。默认保留全部；用户指定每槽位数量、观察年龄或活动库目标后先预览具体候选，再明确移入可重新加入的保留目录。固定记录、每槽位最新已知进度及当前撤回所需记录和目录受到保护。移出只调整活动库占用，原 ZIP 副本完整保留；要回收原件内容空间，需另行选择有可信来源的移出副本、隔离原件或旧回档前目录，指定真实外部 ZIP 路径并逐文件核验后，核对确切目标与数量、填写确认短语。未知来源和当前撤回目录保持保护。原件、保护或外部归档改变时停止；部分失败逐项显示已回收与重建结果，重试必须重新预览。显示的是内容字节，不是文件系统实际空闲簇；默认保留全部，不自动清理。

导出保留预览时的观察时间，正常自动备份检查不会使确认失效；所选备份内容、名称、保护状态或其他所选资料改变时仍须重新预览。预览最多保留最近32份清单，重启后需重新预览。

「选择迁移」可跨槽位选择最多32份历史，核对名称、槽位、游戏保存时间、数量与大小后导出带索引的 ZIP；超过64 MiB需分批，不会省略记录。导入先逐份校验，再明确选择并登记历史，显示各份成功/失败、源保存与观察时间、摘要、大小、源编号和成功后的目标编号，以及失败重试入口，不自动恢复游戏。单份 ZIP 导入导出仍可使用。保留目录导出的存档包用于保存原件，不等同可直接回档的迁移包。

恢复、撤回和移出后的实际结果保留在当前页面的「已提交操作回执」，列出提交时的目录、槽位和记录。取消后续预览或切换目录仍可核对已经发生的操作；新目录加载时会重新显示状态。重新载入页面后需要从当前历史核对，页面回执不作为跨重启日志。

要撤回回档：完全退出游戏，在「存档时光机」选择槽位，点击「撤回上次回档」，核对进度并勾选确认。可跨助手重启撤回，撤回前的当前进度也会另行保留。若回档前副本或当前槽位在检查期间改变，助手会拒绝撤回；关联当前撤回的活动记录不允许移出；即使活动库被外部移走，可读取的撤回记录仍会显示。

独立版的设置、日志和本次服务地址存放在 `%LOCALAPPDATA%\Denghuo\`，与安装目录分离，更新和卸载程序会保留。首次从旧目录启动独立版时，逐文件核对后复制旧设置、备份、收藏方案及健康副本、游玩偏好及明确保存或自动保留的原始草稿；备份连同保留区、隔离区和中断自动整理所需原件一起核对复制，迁移后启用自动整理仍需重新确认；未生成设置文件的默认使用记录也可识别，原文件保留；不兼容的有界草稿原件单独保留并提示，无法解析的有界自动草稿可明确确认后保留原始字节并归档，不再占用自动恢复额度；勾选「显示已归档」可核对摘要并取回原始文件，不能载入为表单。已有独立版数据不会被覆盖。源码版继续使用 `.local/`。分析结果与备份不会上传。服务仅监听 `127.0.0.1`，主面板每次启动使用独立端口。浏览器中保留的旧页面在重启后应由新页面替代；断开连接会清除旧局势，禁止继续带入失效快照，手动表单草稿保留。

## 安装包与本地数据

安装版安装后可直接使用；免安装版 ZIP 需**完整解压**，保留 `_internal` 文件夹，再双击 `灯火.exe`。不能只复制 EXE 或直接在压缩包中运行。Windows 10/11 x64 适用，不需要另装 Python。源码版 ZIP 单独提供，供开发和许可用途，玩游戏时无需打开。

交付包不包含个人设置、存档、日志或开发用源码镜像。第一次运行会使用标准存档目录与默认设置；需要其他路径时在「连接设置」中选择。现有运行目录中的设置保存在 `.local`，更新源码时请保留该目录。

曾使用官方4.0.1游戏新开战士存档，实际探索、自动备份、退出游戏、恢复旧进度并重新进入游戏验证。恢复及撤回后的存档文件均与对应进度逐字节一致；游戏运行期间恢复被拒绝且文件未改变。独立程序另用受控存档验证中文/空格路径、不同工作目录、数值计算、自动捕获变化、校验与正常退出。
