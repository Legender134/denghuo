# 灯火使用指南

## 连接游戏

默认读取 `%APPDATA%\.shatteredpixel\Shattered Pixel Dungeon`，自动选择最近更新的有效槽位。使用自定义目录时，在「更多 → 设置 → 连接与启动」中选择存档根目录。可固定选择 1–6 号槽位。

还没有存档时先开始一局。游戏保存后，助手会自动读取；「旧快照」表示保存时间较早，不等于画面中的实时状态。目录离线、存档损坏或保存尚未完成时会说明原因，有效文件恢复后继续读取。

## 随行窗口

标题栏可拖动，边缘可缩放。点提灯图标收起为小入口，再点展开；当前页面与编辑内容保留。「恢复默认大小与位置」只重置布局。「界面大小」可选择 100%、115% 或 130%。

「本层」查看主动揭示的隐藏内容和有效额外计算；「图鉴」搜索机制与数值；「背包」查看物品并进入装备比较；「存档」查看备份与恢复记录。更多菜单中可打开炼金、方案、未完成草稿、设置和完整面板。

切到其他软件时，随游戏显示的窗口会隐藏。只读提示不抢游戏焦点；展开表单编辑会取得焦点。独占全屏下可能最小化游戏，建议使用窗口化或无边框模式。

## 图鉴与计算

支持中文名、常用别称和用途查询。网页中按 Enter 打开首项、方向下键进入结果、Ctrl+F 返回搜索。没有精确匹配时可选择近似建议。常用条目可收藏。

数值条件会标明快照、已知物品、示例或手填来源。修改条件后需要重新计算；空白和未确认值不会当作零。带入最新角色条件需要主动操作，保存的固定方案不会被新快照自动改写。

治疗、露珠、装备升级与怪物掉落均有适用条件。回合指游戏时间，不是现实秒数；概率不预测下一次掉落。完整数值、条件限制与官方源码依据可展开查看。

## 装备与炼金

从背包选择装备进入比较；按需要设置力量、目标防御和升级预算。预算中的备选各自使用同一份额度，不会实际消耗游戏资源。树脂、诅咒注魔与硬化等条件可能改变结果，请核对界面提示。

炼金按希望制作的产出数量添加目标。多个目标按顺序共用库存、保留量和能量；多种材料分支需要明确选择。未知身份、耐久或随机产物不会当作确定材料。可撤销、重做并保存计划。

## 方案与未完成草稿

数值、装备比较、炼金、角色条件和手动局势可以命名保存为方案。方案保留来源与参数，打开不会自动替换为新角色数值。

退出时如有未完成输入，可选择保存草稿、返回编辑或放弃。下次从「继续编辑草稿」明确载入；载入只恢复输入，不会自动计算、恢复游戏或应用设置。异常中断时可以找回最近已成功上报的副本，最后尚未上报的编辑不保证保留。

## 备份与恢复

助手运行时默认自动备份磁盘上的稳定存档。关闭浏览器或收起窗口不会停止后台；选择「退出灯火」才会结束。立即备份不会强制游戏保存。

在存档历史中可查看、命名、固定、校验与导出记录。恢复或撤回上次回档前必须完全退出游戏，并核对槽位、保存时间和预览。恢复前完整保留当前槽位。Steam 云同步可能随后覆盖本地文件，重新进入游戏后请核对进度。

备份、方案与设置默认位于 `%LOCALAPPDATA%\Denghuo\`，与安装文件分开。更新和卸载保留这些数据。更换备份位置、整理保留区及搬机迁移都有预览与确认，默认不会删除历史。移入保留区只调整活动额度，不会释放磁盘空间；容量或磁盘不足时会提示暂停新增。

成就与排行榜有独立的历史保护与逐文件恢复，普通槽位回档不会覆盖它们。不要把助手备份当作其他磁盘或云盘上的独立副本，重要记录可主动导出。

## 更新与排查

每次启动在后台检查更新。小窗口「更多 → 软件更新」和网页「检查更新」提供手动入口。下载完成后校验大小与 SHA-256，点击「退出并安装」才启动安装。取消退出会保留当前编辑；网络不可用时仍可继续使用本地功能。

安装包与免安装包适用于 Windows 10/11 x64，无需 Python。免安装包必须完整解压并保留 `_internal` 目录。

遇到问题，可从「帮助与关于」查看版本、数据位置与排查摘要，再到 [GitHub Issues](https://github.com/Legender134/denghuo/issues) 描述复现步骤。请先检查截图或附件中是否包含个人存档、路径与其他不想公开的信息。
